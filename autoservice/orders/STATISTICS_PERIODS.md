# Настройка периодов статистики через Django

Периоды графиков задаются **в Django Admin**, а не в Angular и не в 1С.

## Где редактировать

Администрирование Django → **Заказы / Периоды статистики**.

Можно создать любой период от **1 до 90 календарных дней** (включительно), например 14, 21 или 60 дней. Включённые значения попадают в кнопки на странице «Статистика» без пересборки фронтенда; отключённые не отображаются и не принимаются API.

При установке миграции `orders.0032_statistics_period_options` создаются:
- 7 дней;
- 30 дней — по умолчанию;
- 90 дней.

Чтобы сменить период по умолчанию, отметьте **одну** строку списка и выберите действие «Сделать выбранный период периодом по умолчанию». Период должен быть включён. Если период по умолчанию удалён, выбирается минимальный включённый.

Для применения изменений в Django Admin достаточно обновить страницу статистики. Перезапуск сервисов и изменение конфигурации 1С не нужны.

## API

Для активной роли `admin`:
- `GET /api/v1/orders/statistics/periods/` → `{"periods":[{"days":7},{"days":30},{"days":90}],"defaultDays":30}`.
- `GET /api/v1/orders/statistics/?days=30` → агрегаты 1С за выбранный период.

Если `days` опущен, Django использует действующий период по умолчанию. Невключённые, неизвестные периоды и значения более 90 дней отклоняются.

Django переводит `days` в `from/to`, как и прежде. 1С не получает список кнопок и **не меняется**: её HTTP-сервис по-прежнему ограничивает запрос периодом не более 90 дней.

Если нет ни одного включённого периода, endpoint вариантов возвращает пустой список и `defaultDays: null`; фронтенд показывает сообщение о необходимости настроить периоды.

## Развёртывание

1. Влить PR бэкенда и обновить контейнер Django. `entrypoint.sh` автоматически выполняет `python manage.py migrate --noinput`.
2. Убедиться, что миграция `orders.0032_statistics_period_options` прошла и данные появились в Django Admin.
3. Влить PR фронтенда и обновить его контейнер.
4. В Django Admin создать 14 дней, отключить 7 дней и выбрать 14 дней по умолчанию: фронтенд должен получить новый список и отобразить графики за 14 дней. Прямой запрос `?days=7` должен быть отклонён.
